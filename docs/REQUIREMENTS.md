# 기능 요구사항 (Requirements)

## 1. 도메인 개요

반도체 팹(Fab)에서 생산되는 **시료(Sample)** 를 관리하는 시스템.  
고객 주문이 들어오면 재고를 확인하고, 재고 여부에 따라 즉시 출고하거나 생산라인에 생산을 요청한다.

### 1.1 시료(Sample) 종류 (PoC 범위)

| 시료 ID | 시료명 | 생산라인 |
|---------|--------|---------|
| S-001 | DRAM-8Gb | LINE-A |
| S-002 | NAND-128Gb | LINE-B |
| S-003 | Logic-SOC | LINE-C |

## 2. 기능 요구사항 (Functional Requirements)

### FR-01 주문 관리

| ID | 요구사항 |
|----|---------|
| FR-01-1 | 콘솔 입력으로 시료 주문을 등록할 수 있다 |
| FR-01-2 | 주문에는 시료 ID, 수량, 고객 ID, 납기일이 포함된다 |
| FR-01-3 | 등록된 주문 목록을 조회할 수 있다 |
| FR-01-4 | 주문 상태(PENDING → 출고완료)를 추적할 수 있다 |
| FR-01-5 | 주문을 취소할 수 있다 (출고 전 상태에 한함) |

### FR-02 재고 관리

| ID | 요구사항 |
|----|---------|
| FR-02-1 | 시료별 현재 재고 수량을 조회할 수 있다 |
| FR-02-2 | 주문 수량과 재고 수량을 비교하여 출고 가능 여부를 판단한다 |
| FR-02-3 | 출고 처리 시 재고 수량이 차감된다 |
| FR-02-4 | 생산 완료 시 재고 수량이 증가한다 |
| FR-02-5 | 재고 임계값(Threshold) 이하가 되면 경고를 출력한다 |

### FR-03 출고 관리

| ID | 요구사항 |
|----|---------|
| FR-03-1 | 재고가 충분하면 즉시 출고 처리한다 |
| FR-03-2 | 재고가 부족하면 출고 대기 상태로 전환하고 생산을 요청한다 |
| FR-03-3 | 생산 완료 후 자동으로 출고 처리를 재시도한다 |
| FR-03-4 | 출고 이력을 조회할 수 있다 |

### FR-04 생산라인 관리

| ID | 요구사항 |
|----|---------|
| FR-04-1 | 시료별 전용 생산라인이 존재한다 |
| FR-04-2 | 생산라인에 생산 작업(Job)을 등록할 수 있다 |
| FR-04-3 | 생산라인의 현재 상태(IDLE / RUNNING / PAUSED / MAINTENANCE)를 조회할 수 있다 |
| FR-04-4 | 생산 진행률(%)을 콘솔에서 모니터링할 수 있다 |
| FR-04-5 | 생산 완료 시 재고 DB에 수량을 반영하고 대기 주문을 출고한다 |

### FR-05 모니터링 대시보드

| ID | 요구사항 |
|----|---------|
| FR-05-1 | 전체 주문 현황(상태별 건수)을 실시간 표시한다 |
| FR-05-2 | 시료별 재고 현황을 테이블로 표시한다 |
| FR-05-3 | 생산라인별 가동 상태와 진행률을 표시한다 |
| FR-05-4 | 최근 이벤트 로그(주문 등록, 출고, 생산 시작/완료)를 출력한다 |

## 3. 비기능 요구사항 (Non-Functional Requirements)

| ID | 항목 | 내용 |
|----|------|------|
| NFR-01 | 아키텍처 | MVC 패턴을 준수한다. Model은 View를 직접 참조하지 않는다 |
| NFR-02 | 언어/표준 | C++20, MSVC v145 |
| NFR-03 | DB | PoC 범위에서는 인메모리 컨테이너(`std::map`, `std::vector`)로 대체 |
| NFR-04 | 동시성 | 생산라인 시뮬레이션에 `std::thread` 또는 타이머 루프를 사용 |
| NFR-05 | 콘솔 UX | 메뉴 기반 입력, 화면 갱신 시 깜빡임 최소화 |
| NFR-06 | 확장성 | 실제 DB 연동, REST API 확장을 고려한 레이어 분리 |

---

## 4. 주문 상태 정의

```
PENDING           주문 등록 완료, 처리 대기
CHECKING          재고 확인 중
READY_TO_SHIP     재고 확보, 출고 대기
AWAITING_PROD     재고 부족, 생산 요청됨
IN_PRODUCTION     생산라인 가동 중
SHIPPED           출고 완료
CANCELLED         주문 취소
```

## 5. 생산라인 상태 정의

```
IDLE              유휴 (작업 없음)
RUNNING           생산 가동 중
PAUSED            일시 정지
MAINTENANCE       점검 중 (신규 작업 수락 불가)
```
